# Python Basic Projects

This repository contains some Python projects built to practice and improve my Python programming skills.

To run a project, download this repository, open the project folder in your terminal, and run the corresponding Python file.

## 1. Student Management System (`student_project.py`)

- **Description:** This project manages student information.

**Features:**
- Add student details.
- View student information.
- Search for students.
- Update student details.
- Delete student records.

**What needs to be done:** Multiple features + structured code.

## 2. Banking System (`bank_system.py`)

- **Description:** This project simulates basic banking operations using Python.

**Features:**
- Create accounts.
- Deposit money.
- Withdraw money.
- Check account balance.
- Transfer money between accounts.

**What needs to be done:** State management + multiple operations + validations.

## 3. Library Management System (`libary_system.py`)

- **Description:** This project manages books, library members, and book borrowing and returning operations.

**Features:**
- Add and remove books.
- Add library members.
- Search for books.
- Issue books to members.
- Return borrowed books.
- Calculate fines for late returns.

**What needs to be done:** Real-world logic + multiple data relationships.

## 4. Simple Task Management Application ('task_management.py')

- **Description:** A Command-Line To-Do List & Planner is a simple task management application that runs in terminal.

**Features:**
- Add a new task by providing its details.
- Display all the tasks you have added.
- Edit a task (search for the task using its ID and update its information).
- Delete a task using its task ID.
- Change a task status.
- Sort tasks (By priority: High → Medium → Low).

**What needs to be done:** Task organization + priority-based sorting + task status management.
